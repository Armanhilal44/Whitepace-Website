# Whitepace-Website   # White Pace Website

A fully responsive and visually clean website built using HTML and CSS. This project is designed to be user-friendly and adapt seamlessly across different devices including **mobile**, **tablet**, and **desktop** screens.

- Clean and modern UI
- Fully responsive layout using media queries
- Smooth design for different screen sizes

The website layout adjusts automatically to:

- 📱 **Mobile Devices**
- 📟 **Tablets**
- 🖥️ **Desktop Screens**
